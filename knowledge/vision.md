# 願景

## 問題陳述

研讀聖經這類長篇經典時，讀者需要同時掌握宏觀結構與微觀字句，並在互文之間來回比對。紙本有穩固的空間記憶，卻被困在單一尺度、互文相隔數百頁；現行電子書用無盡捲動與超連結跳轉，失去空間記憶與上下文。

搜尋方面，傳統工具只做字面比對：現代人的困境用語（「焦慮」「情緒勒索」「冒名頂替」）在經文中沒有對應字詞，查無結果；純向量檢索又對人名、地名、精確詞句不敏感。而現有的 AI 聖經工具多半是生成式的——替讀者解釋、總結，越過了工具的本分，且依賴雲端，不適合聖經輔導這類涉及隱私的情境。

目前沒有一套專為經典長文本設計、兼顧多尺度幾何閱讀與「只檢索、不解釋」的離線中文語意檢索工具。

## 核心想法

一本離線的「語意串珠聖經」：固定幾何的經文地表 + 可連續縮放的虛擬相機，著陸在確定的結構點上；語意與關鍵字混合檢索、串珠以原位摺疊呈現，不同主題視角是同一結構的不同切面。工具只把讀者帶到經文與它的上下文面前，解釋留給讀者與聖靈。

**使用者**：研經者；聖經輔導員（把受輔者的日常語言橋接到經文現場，查詢不離開裝置）。

## 架構（已定）

- Web PWA，全離線（Service Worker；模型與資料打包在本地）——跨手機／平板／桌面，日後可包成 App。離線同時是隱私保證：查詢不離開裝置。
- 譯本：和合本 CUV（公有領域），採「神版」。
- 經文資料來源：信望愛聖經工具（FHL）。
- 檢索：只用 embedding 與關鍵字，不含任何生成模型（見 principles 衍生原則 4）。
- 參考典範：Henle Library / forScore（固定版面、翻頁）、Google Maps（LOD 縮放）、LiquidText（摺疊比對）。
- 範圍策略：檢索涵蓋全本；閱讀器先以羅馬書（及其引用的舊約段落）做完整深度，確認手感後再擴充至全本。
