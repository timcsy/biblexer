# Phase 0 研究：固定幾何閱讀器與語意縮放

**日期**：2026-10-05 ｜ **Spec**：[spec.md](./spec.md)

本功能的未知數都是版面與互動的設計決定，不涉及新的外部資料或套件；以下依據羅馬書的實際資料（433 節、16 章、約 14,280 字；非漢字只有全形標點、神版抬頭空白「　」175 處、半形「.」4 處；最長一節 90 字）做決定。

---

## R1. 方格排版：換行只由格數決定

**Decision**：每個字元佔一格（全形、半形、抬頭空白皆同），每行 **18 格**、每欄 **16 行**、每頁 **2 欄**。版面在 TypeScript 中以純函式計算（`layoutBook`），輸出每一格的座標；渲染時每格是固定寬度的方格，不依賴字型的字寬。

**Rationale**：
- 原則 1 要求跨裝置位置相同。只要換行由格數決定，就與字型、字寬、裝置無關——傳統中文書本來就是方格排版。
- 18 格：手機約 390 px 寬，扣邊距後每格約 19～20 px，可讀；16 行：行高 1.75 時一欄約 550 px，能完整放進多數手機的可視高度（FR-011 不切行）。
- 全書約 1,000 行 → 約 62 欄、31 頁。

**Alternatives considered**：依視窗寬度 reflow（違反原則 1）；以字型等寬假設排版（標點在不同字型寬度不同，不可靠）；Canvas 繪字（可行，但失去文字選取與無障礙；DOM 方格已足夠快，見 R5）。

## R2. 排版規則（全部決定性）

| 規則 | 決定 |
|---|---|
| 段落起點 | 新的一行，首行縮排 2 格 |
| 章起點 | 新的一行，先佔一行章號標籤「第 8 章」（結構標籤，非編者標題） |
| 節號 | 半形數字，以上標呈現，固定佔 1 格（1～2 位數）或 2 格（3 位數以上不會出現在羅馬書） |
| 合併節 | 佔位節不佔格；承載節的節號顯示為範圍（「29–30」，固定佔 2 格） |
| 和合本譯註 | 與正文一起排，每字一格，以次要樣式呈現 |
| 行首禁則 | 結尾標點（，。、；：？！」』）】〉─）不出現在行首：行尾懸掛（允許該行第 19 格放這一個標點） |
| 行尾禁則 | 開頭標點（「『（【〈）不出現在行尾：移到下一行 |
| 跨行、跨欄、跨頁 | 經文直接接續；一節的座標以起始格為準，另記結束格 |

**Rationale**：規則簡單、可測（性質測試：每行格數 ≤ 18（懸掛時 ≤ 19）、行首不為結尾標點、行尾不為開頭標點）。章號與節號是結構標籤，不是詮釋，符合原則 4、9。

## R3. 世界座標與頁面配置

**Decision**：以「格」為世界座標單位。頁面在世界中排成網格：**每列 6 頁**、由左而右、由上而下；頁內兩欄左右排列。閱讀順序：欄 → 下一欄 → 下一頁 → 下一列。正典層級的 66 卷以等大的方塊排成 **每列 11 卷、6 列**（依正典順序），羅馬書方塊就是它的頁面網格本身——所以從正典連續縮放到精讀是同一個幾何空間，不是切換畫面。

**Rationale**：原則 2「探索空間就是文本自身的結構」——縮放沿正典順序、書卷、章、段落移動；連續縮放需要所有層級在同一個世界中（根公理「連續地探索」）。

## R4. 縮放層級、著陸點與吸附

**Decision**：相機＝`{ x, y, scale }`（世界座標 → 螢幕像素）。以「精讀比例 r」為基準（手機上一欄寬剛好填滿視窗；桌機上一頁剛好填滿），依比例分成四個層級：

| 層級 | 比例範圍 | 呈現 | 著陸點 |
|---|---|---|---|
| 精讀 | ≥ 0.6r | 方格文字 | 段落起點、欄頂端 |
| 段落輪廓 | 0.25r～0.6r | 每行以長條表示（保留段落形狀）＋段落範圍與開頭字句 | 段落起點 |
| 書卷 | 0.06r～0.25r | 頁面縮圖＋章號 | 章起點 |
| 正典 | < 0.06r | 66 卷方塊 | 書卷 |

吸附：放手時依目前比例決定層級，比例吸附到該層級的標準比例，位置吸附到該層級最近的著陸點（距離以世界座標中著陸點的錨點到視窗錨點計算）。

**「回到原處」（FR-010）**：相機另記 `focus`——最近一次在精讀層級停留的著陸點。縮小時只要不平移，`focus` 保留；放大回精讀層級時，優先回到 `focus`，而不是「最近」的著陸點。平移即清除 `focus`。這讓「縮小再放大回到原處」成為可證明的性質。

**不切行（FR-011）**：精讀層級的可見區域高度取整數行（`floor(視窗高 / 行高)`），多出的部分以遮罩隱藏；吸附後頂端對齊行的上緣。

**Rationale**：每個層級的著陸點集合都由既有結構定義（原則 3）；吸附是「離散地著陸」的實作。層級名稱用平實用語（FR-017）。

**Alternatives considered**：以 Farey 頂點為著陸點（仍有未解問題，留待階段 4，見 `knowledge/draft/2026-09-30-Farey定址座標系.md`）；連續比例不分層（無法定義著陸點集合，違反原則 3）。

## R5. 渲染與效能

**Decision**：DOM 渲染、虛擬化：世界容器用 CSS `transform: translate() scale()` 表示相機；精讀與段落輪廓層只渲染視窗附近的頁（前後各 1 頁），每格一個固定寬度的方格元素；書卷與正典層級以頁面縮圖（不渲染文字）呈現。手勢以 Pointer Events（雙指縮放、拖曳）、`wheel`（觸控板／滑鼠）、按鈕與鍵盤（＋／−、方向鍵）處理；連續縮放期間只更新 transform，放手後才吸附並重新虛擬化。

**Rationale**：一頁最多 2×16×19 ≈ 600 格，三頁約 1,800 個元素，DOM 足以應付；保留文字選取與螢幕閱讀器。transform 只觸發合成，縮放流暢（SC-005）。

## R6. 與階段 1 的連接

**Decision**：閱讀器是同一個 app 的一個視圖（與搜尋結果並列），沿用 Worker 已載入的經文與段落；新增 Worker 訊息 `book`（取得一卷的經節與段落）。搜尋結果若在羅馬書範圍內，顯示「在閱讀器中開啟」；開啟時把相機放在命中段落起點的精讀著陸點、標示命中範圍，並記住搜尋狀態以便返回。

## R7. 測試策略（constitution：TDD）

| 對象 | 測試 |
|---|---|
| 排版 | 單元＋性質：每行格數上限、禁則、段落／章起點換行、每節恰有一個起始座標、座標遞增、與視窗無關（純函式不接收視窗參數） |
| 層級與著陸點 | 性質：著陸點集合依層級正確；吸附冪等、結果屬於集合；`focus` 下縮小再放大回原處；比例越界時停在邊界 |
| 跨裝置一致（SC-001） | E2E：三種視窗寬度下讀出全部 433 節的 `data-pos`，三者相同 |
| 不切行（SC-002） | E2E：精讀層級吸附後，所有可見行的上下緣都在可見區域內 |
| 搜尋 → 閱讀器（SC-004） | E2E |
| 流暢度、跨裝置找回位置（SC-005、SC-006） | 手動驗證（quickstart） |
