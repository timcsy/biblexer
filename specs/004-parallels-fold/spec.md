# 功能規格：串珠（語意近鄰）與原位摺疊比對（羅馬書切片）

**Feature Branch**: `004-parallels-fold`

**Created**: 2026-10-05

**Status**: Ready（2026-10-07 修訂：資料來源已於 2026-10-06 由使用者決定——第一層用 UBS Parallel Passages Database 的明引、一般串珠用 TSK，見 `knowledge/concepts/西敏神學院傳統是設計準則.md`；新增 User Story 3、FR-007～FR-013）

**Input**：由 knowie-next 依 vision 階段 3 整理（使用者授權「照推薦的決策，不能決定的先記錄，先做可以自動決策的部分」）：階段 3 交付「羅馬書每節的串珠（引用資料＋語意近鄰），以原位摺疊比對呈現」。引用資料的來源屬帶神學意涵的選擇（原則 8），待使用者決定；本規格先做語意近鄰（原則 9：語意相似度屬檢索能力，不是詮釋）與原位摺疊比對，並為第一層預留分層與署名。

**相關原則**：衍生原則 2（「跨卷關聯用摺疊／靠攏呈現，不用跳轉」）、5（串珠、摺疊比對都必須能展開前後文）、6（標示相關，不標示權威）、9（署名）；`concepts/西敏神學院傳統是設計準則.md`（新約引用舊約為第一層，優先於語意近鄰）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在閱讀器裡看到這一段的可能相關段落（Priority: P1）

讀到羅 8:28 那一段，按「串珠」，旁邊展開一列「語意上可能相關的段落」——來自整本聖經、不含本章——每一筆標出處與經文開頭。

**Independent Test**：閱讀器停在某段，按「串珠」，面板列出至少一筆不在本章的段落，標示為語意相似（不顯示分數）。

**Acceptance Scenarios**：
1. **Given** 閱讀器停在某段且語意檢索已就緒，**When** 按「串珠」，**Then** 側邊面板列出可能相關的段落（出處＋經文），不含同一章的段落，不顯示任何分數或「推薦」字眼。
2. **Given** 面板已開，**When** 用方向鍵移到下一段，**Then** 面板改列新段落的可能相關段落。
3. **Given** 語意檢索尚未就緒，**When** 按「串珠」，**Then** 面板以中性文字說明「語意檢索準備中」，不顯示空清單以外的內容。

### User Story 2 - 原位摺疊比對，放開後閱讀位置不變（Priority: P1）

在面板點一筆，那段經文在面板中展開成完整段落（可再展開全章），與正在讀的段落並排比對；關掉後，閱讀器停在原來的位置，沒有跳轉。

**Independent Test**：記下閱讀器的著陸點與畫面位置，展開比對再關閉，兩者完全不變。

**Acceptance Scenarios**：
1. **Given** 面板中的一筆，**When** 點它，**Then** 該段完整經文（含節號與譯註）在面板中展開，並可「展開全章」。
2. **Given** 正在比對，**When** 關閉比對或面板，**Then** 閱讀器的著陸點與畫面位置與開啟前完全相同（vision 階段 3 成功標準）。

### User Story 3 - 經文本身的關聯：新約引用舊約、TSK 串珠（Priority: P1）

讀羅 1:17（「義人必因信得生」），按「串珠」，面板最上面一層列出它明白引用的舊約經文（哈 2:4），並署名資料來源；第二層列出 TSK 的串珠；語意近鄰在最後。讀哈 2:4 時，第一層反過來列出引用它的新約經文（羅 1:17、加 3:11、來 10:38）。

**Why this priority**：新約對舊約的引用是經文本身的關係（以經解經），依設計準則應作為第一層，優先於語意近鄰。

**Independent Test**：在羅 1 章那一段開串珠，第一層出現哈 2:4、標示資料來源；關掉第一層後重開面板，第一層不出現。

**Acceptance Scenarios**：
1. **Given** 閱讀器停在羅 1:16–17 所在段落，**When** 按「串珠」，**Then** 第一層「新約引用舊約（明引）」列出哈 2:4，並署名 UBS Parallel Passages Database 與授權。
2. **Given** 閱讀器停在哈 2:4 所在段落，**When** 按「串珠」，**Then** 第一層列出引用它的新約經文（含羅 1:17）。
3. **Given** 閱讀器停在羅 8:28 所在段落，**When** 按「串珠」，**Then** TSK 層列出 TSK 為這幾節彙編的參照（含創 50:20），署名 TSK 與彙編者，不顯示 TSK 的英文分組標題。
4. **Given** 任一層，**When** 讀者關閉該層，**Then** 該層不再出現（記在這個瀏覽器），其他層不受影響。
5. **Given** 語意檢索尚未就緒，**When** 按「串珠」，**Then** 第一層與 TSK 層照常顯示，只有語意近鄰層顯示「準備中」。

### Edge Cases

- 語意近鄰為空（極短段落、資料缺失）：顯示「沒有找到相關段落」。
- 合併節、譯註：與閱讀器相同的呈現。
- 面板在手機上：覆蓋畫面下半部，不改變閱讀版面（原則 1）。
- 第一層（新約引用舊約）或 TSK 在這一段沒有任何參照時：不顯示該層的標題（不出現系統產生的佔位文字）。
- 經節編號不同：UBS 舊約用希伯來文聖經的編號，經 UBS 的編號對照表換算為和合本所用的英文編號；TSK 用 KJV 編號。換算後在和合本中不存在的經節（如約 7:53）略過，建置時列出略過的數目。
- 參照落在合併節（如 29–30）的後一節：視為那個合併節。
- 參照與目前段落重疊：不列出。
- UBS 缺漏的明引（如羅 15:9、15:10）：不補；日後若補，須標示補錄人並以紙本索引人工核對。

## Requirements *(mandatory)*

- **FR-001**：閱讀器 MUST 提供「串珠」，列出目前段落在整本聖經中語意上可能相關的段落（最多 8 筆），MUST 排除同一章的段落與自身。
- **FR-002**：串珠清單 MUST 依相似度排序但 MUST NOT 顯示分數；標題 MUST 為中性用語（「語意上可能相關的段落」），並標明依據（語意相似度、模型名稱）。
- **FR-003**：串珠 MUST 分層：第一層「新約引用舊約」（資料來源待定，署名）在前、語意近鄰在後；第一層資料不存在時不顯示該層。
- **FR-004**：點一筆 MUST 在面板中原位展開該段完整經文，並可展開全章（原則 5）；MUST NOT 移動閱讀器。
- **FR-005**：開啟、比對、關閉的整個過程 MUST NOT 改變閱讀器的著陸點與相機位置。
- **FR-006**：串珠的計算 MUST 完全在裝置上進行，不新增網路請求。
- **FR-007**：第一層 MUST 列出目前段落各節在 UBS Parallel Passages Database 中的明引關係（同一組同時含舊約與新約經節者），雙向：新約段落列出所引的舊約，舊約段落列出引用它的新約；MUST 署名「UBS Parallel Passages Database，© 2023 United Bible Societies，CC BY-SA 4.0」並註明「只收明引」。
- **FR-008**：TSK 層 MUST 列出目前段落各節在 TSK 中的參照，依 TSK 原有順序、去除重複；MUST 署名「Treasury of Scripture Knowledge（約 1830 年 Bagster 彙編，取自 Canne、Blayney、Scott 等人的旁註；公共領域）」；MUST NOT 顯示 TSK 的英文分組標題與英文旁註。
- **FR-009**：層的順序 MUST 為 第一層（明引）→ TSK → 語意近鄰；每一層 MUST 有中性標題與自己的署名；某層在這一段沒有參照時不顯示。
- **FR-010**：每一層 MUST 可以由讀者關閉與重新開啟，選擇記在這個瀏覽器。
- **FR-011**：參照的每一筆 MUST 顯示所指的經節範圍（不擴大為整段），點開後原位展開，並可展開全章（原則 5，同 FR-004）。
- **FR-012**：UBS 資料（CC BY-SA 4.0）MUST 以獨立的資料檔與授權檔發布，不與其他資料合併；建置時記錄來源網址、版本（提交雜湊）與檔案雜湊。
- **FR-013**：第一層與 TSK 層 MUST 不依賴語意模型：語意檢索未就緒時照常顯示。

### Key Entities

- **串珠項（Parallel）**：層級（quote｜tsk｜semantic）、出處、經節範圍（quote、tsk）或段落範圍（semantic）、經文；每層附署名。
- **參照表（Cross-reference table）**：每一節 → 一串目標經節範圍；明引與 TSK 各一份、各自署名與授權。

## Success Criteria *(mandatory)*

- **SC-001**：在羅馬書任一段開啟串珠，1 秒內出現清單（中階桌機，手動驗證）。
- **SC-002**：比對前後閱讀位置 100% 不變（E2E）。
- **SC-003**：清單中 0 筆同章段落、0 個分數（E2E＋單元）。
- **SC-004**：UBS 中羅馬書的明引，換算後 100% 落在和合本存在的經節上（資料測試）；全本略過的數目列在建置紀錄中。
- **SC-005**：羅 1:17 的第一層含哈 2:4、哈 2:4 的第一層含羅 1:17；羅 8:28 的 TSK 層含創 50:20（資料測試＋E2E）。

## Assumptions

- 段落向量＝該段所有檢索單元向量的平均（正規化）；與每段的相似度取其單元的最大值。
- 只在閱讀器（羅馬書）提供；搜尋結果的串珠不在本範圍。
- 暗引：沒有開放資料，不做；日後若做須由具名編者人工建立。
- UBS 資料中的舊約內部平行（如列王紀與歷代志）與對觀福音平行：本次不收（決定只收新約引用舊約）；記在草稿，日後可另議。
