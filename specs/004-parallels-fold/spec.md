# 功能規格：串珠（語意近鄰）與原位摺疊比對（羅馬書切片）

**Feature Branch**: `004-parallels-fold`

**Created**: 2026-10-05

**Status**: Ready（部分：串珠第一層「新約引用舊約」的資料來源待使用者決定，見 `knowledge/draft/2026-10-05-待使用者決定.md`）

**Input**：由 knowie-next 依 vision 階段 3 整理（使用者授權「照推薦的決策，不能決定的先記錄，先做可以自動決策的部分」）：階段 3 交付「羅馬書每節的串珠（引用資料＋語意近鄰），以原位摺疊比對呈現」。引用資料的來源屬帶神學意涵的選擇（原則 8），待使用者決定；本規格先做語意近鄰（原則 9：語意相似度屬檢索能力，不是詮釋）與原位摺疊比對，並為第一層預留分層與署名。

**相關原則**：衍生原則 2（「跨卷關聯用摺疊／靠攏呈現，不用跳轉」）、5（串珠、摺疊比對都必須能展開前後文）、6（標示相關，不標示權威）、9（署名）；`concepts/西敏神學院傳統是設計準則.md`（新約引用舊約為第一層，優先於語意近鄰）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在閱讀器裡看到這一段的可能相關段落（Priority: P1）

讀到羅 8:28 那一段，按「串珠」，旁邊展開一列「語意上可能相關的段落」——來自整本聖經、不含本章——每一筆標出處與經文開頭。

**Independent Test**：閱讀器停在某段，按「串珠」，面板列出至少一筆不在本章的段落，標示為語意相似（不顯示分數）。

**Acceptance Scenarios**：
1. **Given** 閱讀器停在某段且語意檢索已就緒，**When** 按「串珠」，**Then** 側邊面板列出可能相關的段落（出處＋經文），不含同一章的段落，不顯示任何分數或「推薦」字眼。
2. **Given** 面板已開，**When** 用方向鍵移到下一段，**Then** 面板改列新段落的可能相關段落。
3. **Given** 語意檢索尚未就緒，**When** 按「串珠」，**Then** 面板以中性文字說明「語意檢索準備中」，不顯示空清單以外的內容。

### User Story 2 - 原位摺疊比對，放開後閱讀位置不變（Priority: P1）

在面板點一筆，那段經文在面板中展開成完整段落（可再展開全章），與正在讀的段落並排比對；關掉後，閱讀器停在原來的位置，沒有跳轉。

**Independent Test**：記下閱讀器的著陸點與畫面位置，展開比對再關閉，兩者完全不變。

**Acceptance Scenarios**：
1. **Given** 面板中的一筆，**When** 點它，**Then** 該段完整經文（含節號與譯註）在面板中展開，並可「展開全章」。
2. **Given** 正在比對，**When** 關閉比對或面板，**Then** 閱讀器的著陸點與畫面位置與開啟前完全相同（vision 階段 3 成功標準）。

### Edge Cases

- 語意近鄰為空（極短段落、資料缺失）：顯示「沒有找到相關段落」。
- 合併節、譯註：與閱讀器相同的呈現。
- 面板在手機上：覆蓋畫面下半部，不改變閱讀版面（原則 1）。
- 第一層（新約引用舊約）資料尚未加入時：不顯示空的第一層標題（不出現系統產生的佔位文字）。

## Requirements *(mandatory)*

- **FR-001**：閱讀器 MUST 提供「串珠」，列出目前段落在整本聖經中語意上可能相關的段落（最多 8 筆），MUST 排除同一章的段落與自身。
- **FR-002**：串珠清單 MUST 依相似度排序但 MUST NOT 顯示分數；標題 MUST 為中性用語（「語意上可能相關的段落」），並標明依據（語意相似度、模型名稱）。
- **FR-003**：串珠 MUST 分層：第一層「新約引用舊約」（資料來源待定，署名）在前、語意近鄰在後；第一層資料不存在時不顯示該層。
- **FR-004**：點一筆 MUST 在面板中原位展開該段完整經文，並可展開全章（原則 5）；MUST NOT 移動閱讀器。
- **FR-005**：開啟、比對、關閉的整個過程 MUST NOT 改變閱讀器的著陸點與相機位置。
- **FR-006**：串珠的計算 MUST 完全在裝置上進行，不新增網路請求。

### Key Entities

- **串珠項（Parallel）**：層級（quotation｜semantic）、出處、段落範圍、經文；semantic 層附依據（模型）。

## Success Criteria *(mandatory)*

- **SC-001**：在羅馬書任一段開啟串珠，1 秒內出現清單（中階桌機，手動驗證）。
- **SC-002**：比對前後閱讀位置 100% 不變（E2E）。
- **SC-003**：清單中 0 筆同章段落、0 個分數（E2E＋單元）。

## Assumptions

- 段落向量＝該段所有檢索單元向量的平均（正規化）；與每段的相似度取其單元的最大值。
- 只在閱讀器（羅馬書）提供；搜尋結果的串珠不在本範圍。
- 第一層資料、暗引、TSK 一般串珠：待使用者決定資料來源後另開任務。
