# Quickstart：驗證經文卡

## 自動化

```bash
npm test      # 經文卡純函式、段落解析、Worker 訊息、字串守護
npm run e2e   # e2e/card.spec.ts
```

| 情境 | 驗證 |
|---|---|
| 加入與去重 | 搜尋「覺得神離我很遠」，加入三段；再按同一段不重複 |
| 整理 | 上移、移除、清空 |
| 保留 | 重新整理（含離線）後內容與順序不變 |
| 列印頁白名單（SC-002） | 列印頁所有文字都在 `data-kind` 白名單元素內；含書寫欄位與署名；無操作介面 |
| 上下文 | 「節」檢視加入單節 → 卡片呈現整段並標示該節 |
| 閱讀器 | 停在某段按「加入經文卡」→ 卡片出現該段 |

## 手動

1. 從搜尋到開啟列印，計時是否在 1 分鐘內（SC-001）。
2. 實際列印一張 A4，在書寫欄位手寫三行（SC-005）。
