# BibLexer 語意串珠聖經

一本**離線**的中文聖經語意檢索工具（和合本神版）。輸入日常的描述或關鍵字，找出可能相關的經文段落，並附上前後文。

## 定位：工具只指路，不代言

- 系統回傳的永遠是**經文原文與它的上下文**；解釋權屬於讀者與聖靈。
- 不含任何文字生成模型（LLM），不產生解釋、摘要或建議；結果只標示「可能相關」，不顯示分數。
- 凡含人為判斷的資料（段落分段、辭典近義詞、原文分組）都標明來源。
- 找不到時，請換個說法——工具不替讀者做詮釋上的推論。

原則的完整內容與由來見 [`knowledge/principles.md`](knowledge/principles.md)。

## 功能（階段 1）

- 語意＋關鍵字混合檢索，以段落呈現並附前後文；可切換「節／段／章」檢視
- 現代用語的詞彙擴充（教育部《重編國語辭典修訂本》近義詞＋原文同字），擴充內容與來源都列在畫面上，可關閉
- 經文出處查詢（如「羅 8:28」「羅馬書8章28節」）、簡體輸入、命中字詞標示
- 展開全章、附出處複製、舊約／新約兩層分類篩選
- 首次載入後完全離線（PWA），查詢不離開裝置；首次下載約 94 MB

## 功能（階段 2、4：固定幾何閱讀器，全本 66 卷）

- 方格排版（每行 18 格、每欄 16 行、每頁 2 欄）：同一節在手機、平板、桌機上的頁／欄／行／格完全相同，視窗大小只改變相機，不重新排版
- 冊頁長卷：精讀時頁一頁接一頁往右、不換列；永遠看到完整的一頁（手機一欄），目前的段落以左側標示線呈現（可切換為「每列六頁」）
- 連續縮放：精讀 → 段落輪廓 → 書卷 → 正典；放手一律吸附到結構上的著陸點，縮小再放大回到原處；移動以連續過場呈現
- 書卷層全貌：章節地圖（一章一列、每塊一段、章號對齊左側）或頁面網格（每列六頁、章號對齊每列左側）
- 找章節：拖動下方有章刻度的進度條，或縮小後點章號、點段落直接進入
- 操作：滾輪或觸控板雙指捲動翻頁、拖曳平移、Ctrl＋滾輪或雙指捏合縮放、畫面上的 ＋／−；鍵盤 PageUp／PageDown 翻頁（手機翻欄）、方向鍵上／下一段、＋／− 縮放
- 羅馬書範圍內的搜尋結果可「在閱讀器中開啟」，落在命中段落並標示命中範圍

## 功能（階段 3：串珠）

- 閱讀器「串珠」分三層，每層各自署名、可收起：
  1. 新約引用舊約（明引）：UBS Parallel Passages Database（CC BY-SA 4.0），雙向——讀新約看到所引的舊約，讀舊約看到引用它的新約
  2. TSK：Treasury of Scripture Knowledge（公共領域）的參照，不顯示英文分組標題
  3. 語意上可能相關的段落（不含本章、不顯示分數，標明依據的語意模型）
- 每一筆可原位展開比對、展開全章，關閉後閱讀位置不變；明引與 TSK 不依賴語意模型，離線可用

## 功能（階段 6：讀者自己的記號）

- 精讀時點節號，為該節加上或取消記號；記號只存在這台裝置的瀏覽器
- 拉遠到段落輪廓、書卷層時，記號是該節旁邊的色條，不會縮到看不見
- 進度條上有記號點（像紙本的書籤）；拖到附近會吸到那一節
- 記號不改動版面座標，也不出現在經文卡

## 功能（階段 5：經文卡）

- 從搜尋結果或閱讀器加入段落，整理順序後列印或存成 PDF；用途不限（背經、查經、講道預備、聖經輔導）
- 卡片只含經文段落（出處與段落範圍，單節會展開為所在段落並標示）、空白書寫欄位與資料來源署名，不含任何系統產生的文字
- 經文卡只存在自己的裝置上，離線可用

## 開發

需要 Node 24。

```bash
npm install
npm run build:data        # 下載並核對來源資料，產生 public/data、public/models、public/ort
npm run dev               # 開發伺服器（不含 Service Worker）
npm run build && npm run preview   # 正式建置與預覽（含離線功能）
```

測試（本專案採 TDD，見 [`.specify/memory/constitution.md`](.specify/memory/constitution.md)）：

```bash
npm test                  # 單元、性質與守護測試
npm run test:data         # 建置產物完整性、首次下載量（需先 build:data 與 build）
npm run test:acceptance   # 固定查詢驗收
npm run bench             # 模型評測，輸出 bench/report.md
npm run e2e               # 端到端測試（含離線與不外洩；E2E_PORT 可改預覽埠號，預設 4173）
npm run lint && npm run typecheck
```

驗證步驟見 [`specs/001-offline-hybrid-search/quickstart.md`](specs/001-offline-hybrid-search/quickstart.md)；資料來源與授權見 [`docs/資料來源.md`](docs/資料來源.md)。

## 部署

推送到 `main` 時，GitHub Actions（`.github/workflows/pages.yml`）會在 CI 上從頭建出所有資料與語意向量，並部署到 GitHub Pages（`https://timcsy.github.io/biblexer/`）。網站可放在子路徑：建置時以 `BASE_PATH` 指定（預設 `/`）。也可以在 Actions 頁面手動執行。

### 已安裝的 App 怎麼更新

- 連網開啟時在背景檢查新版；新版接手後畫面會提示「已更新到新版本」，按「重新載入」即可。App 從背景回到前景時也會檢查一次。
- 資料只下載有變的檔案：資料檔名帶內容雜湊，同名即同內容；模型與 ORT 依 manifest 的 `integrity` 比對。全部下載完成才刪除舊版本，離線時沿用舊版。
- 個人資料（記號、經文卡、設定）存在裝置上，更新時保留。
